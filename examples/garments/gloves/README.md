# Fingerhandschuhe

*English version: [README.en.md](README.en.md)*

Als Umriss-Handschuh oder mit Schichteln (Fourchettes) und eingesetztem Daumen.

<img src="cover.png" alt="Fingerhandschuhe" width="560">

Modul: `gloves` · Beispielbild: Damengröße 38

## Beispiel-Prompts für alle Optionen

| Option | Prompt |
|---|---|
| `style = outline, fourchette` | *„Handschuhe mit Schichteln aus Fleece.“* |
| `hand_circ, hand_length` | *„Handschuhe für Handumfang 19 cm, Handlänge 18 cm.“* |
