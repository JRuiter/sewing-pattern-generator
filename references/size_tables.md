# Size tables

All values in **cm**, body measurements (not finished measurements). The code keeps them in mm
(`measurements.size_measures`, `complete_measures`).

## Source and validity

The tables are **our own smoothed average values**, derived from publicly available
information on ready-to-wear sizes (kids' size = body height in cm, women's and men's sizes
in the system common in Germany, guided by DIN EN 13402-3 and generally known proportion
rules of garment drafting). They do not come from any copyrighted pattern system and are not
a copy of a manufacturer's table. Individual brands differ by 1–3 cm.

Therefore: **the user's measured body measurements always take precedence.** A size alone is
only used when no measurements are given; the skill says in its reply which measurements come
from the table.

## Derived measurements (when not measured)

| Measurement | Kids | Adults |
|---|---|---|
| Body height | = kids' size | women 168 cm, men 176–181 cm |
| Rise (crotch depth) | side length − inseam | side length − inseam |
| Thigh | 0.56 × hip | 0.58 × hip |
| Knee | 0.40 × hip | 0.38 × hip |
| Ankle | 0.27 × hip | 0.24 × hip |
| Upper arm | 0.30 × chest | 0.31 × chest |
| Wrist | 0.20 × chest | 0.17 × chest |

If the user gives, for example, only the hip, thigh and knee are scaled in proportion to the
measured hip (source "derived").

Plausibility check (`validate_measures`) relative to body height: inseam 0.35–0.50, side
length 0.50–0.66, rise 0.10–0.20, arm length 0.36–0.62; also waist ≤ 1.15 × hip. Deviations
appear as a warning in the sewing instructions; nothing is corrected silently.

## Measurement files (.smis / .vit)

`scripts/measure_files.py` reads and writes the XML measurement files of open-source
pattern CAD programs. Units mm, cm and inch are converted; values may be simple formulas
referencing other measurements in the file. Name mapping:

| Skill key | Name in the file |
|---|---|
| `height` | `height` |
| `chest` | `bust_circ` (fallback `body_bust_circ`, `highbust_circ`) |
| `waist` | `waist_circ` |
| `hip` | `hip_circ` |
| `head` | `head_circ` |
| `neck` | `neck_circ` (fallback `neck_mid_circ`) |
| `inseam` | `leg_crotch_to_floor` |
| `side_length` | `height_waist_side` |
| `crotch_depth` | `rise_length_side_sitting` |
| `arm` | `arm_shoulder_tip_to_wrist` |
| `back_length` | `neck_back_to_waist_b` (fallback `neck_back_to_waist_side`) |
| `shoulder` | `shoulder_length` |
| `upper_arm` | `arm_upper_circ` |
| `wrist` | `arm_wrist_circ` |
| `thigh` | `leg_thigh_upper_circ` (fallback `leg_thigh_mid_circ`) |
| `knee` | `leg_knee_circ` |
| `ankle` | `leg_ankle_circ` (fallback `leg_ankle_high_circ`) |

Other measurements in the file are ignored (listed as a warning). The kids' table is
checked by a test: every column grows with the size and no step is an outlier.

## How to measure (short version for users)

- **Chest:** horizontally around the fullest part, loosely, without constricting.
- **Waist:** the narrowest part, or where the waistband should sit.
- **Hip:** the fullest part of the seat, feet together.
- **Inseam:** inside the leg from the crotch to the floor (barefoot).
- **Side length:** at the side from the waist to the floor.
- **Arm length:** from the shoulder point over the slightly bent elbow to the wrist.
- **Head:** around the forehead and the back of the head.

## US and UK sizes (`us8`, `uk12`, `us3t`, `usk8`)

US/UK sizes are mapped onto the tables above; the body measurements then come from there (and
are overridden by any measurement the user gives). The mapping follows the conversions that
are commonly published for ready-to-wear (EU/German size ↔ US/UK size, children's sizes ↔
body height) and the body-measurement ranges of the standard size charts named below. They are
rounded reference values, not a copy of any brand's chart; individual brands differ by a size.

| Input | System | Mapped to | Range |
|---|---|---|---|
| `us0` … `us20` | US women's / misses | women's size = US + 30 (US 8 ≈ 38: chest 88, waist 72, hip 98 cm) | 0–20 |
| `uk4` … `uk22` | UK women's | women's size = UK + 26 (UK 12 ≈ 38) | 4–22 |
| `us2t` … `us5t` | US toddler | kids' size (height) 2T → 92, 3T → 98, 4T → 104, 5T → 110 | 2T–5T |
| `usk4` … `usk16` (`us kids 8`) | US children | kids' size 4 → 104, 5 → 110, 6 → 116, 7 → 122, 8 → 128, 10 → 140, 12 → 152, 14 → 158, 16 → 164 (interpolated in between) | 4–16 |

Sources for the ranges (body measurements, not garment measurements):
- ASTM D5585 (US misses/women's body measurements, sizes 00–20)
- ASTM D6192 (US girls, sizes 2–20) and ASTM D6458 (US boys, sizes 8–14/16)
- BS EN 13402-3 / DIN EN 13402-3 (European body-dimension based size designation; UK
  women's sizes = EU − 26 in common retail practice)

## Units (`--units imperial`)

`units: "metric"` (default) or `"imperial"` (spec field `units`, CLI `--units`).
- Input: with `--units imperial`, `--measures` is read in **inches**; in a spec file use
  `measures_in` (inches) or `measures_cm`.
- Reports in inches (rounded to 1/8"): body measurements, finished measurements, seam
  allowances on the pieces and in the instructions; fabric consumption in **yards rounded up
  to 1/8 yd**, fabric width in inches.
- Pattern files stay 1:1 (mm internally); every print has both the 5 × 5 cm and the 1 inch
  control square. The validation report stays metric.

## Saved measurement profiles (`--profile lena`)

For people you sew for again and again (children who grow, partner, yourself), measurements
can be saved once as `profiles/<name>.json` (directory `--profiles-dir`, environment variable
`SEWING_PROFILES`, default `./profiles`) with `scripts/profiles.py`:

```json
{"name": "lena", "kind": "child", "measured": "2026-11-06",
 "measures_cm": {"height": 121, "chest": 61, "waist": 55, "hip": 64, "inseam": 53},
 "fit": "normal", "default_format": "roll610",
 "history": [{"measured": "2026-05-02", "measures_cm": {"height": 116, "hip": 62}}]}
```

| Field | Meaning |
|---|---|
| `name` | file name / display name |
| `kind` | `child` or `adult` (without it: child if height < 160 cm) |
| `measured` | date the measurements were taken (ISO) |
| `measures_cm` | body measurements in cm, same names as `--measures` (German names accepted) |
| `fit`, `default_format` | used when the request does not name a fit / output format |
| `history` | earlier entries, written automatically by `profiles.py save` |

Precedence: **size table < profile < measurement file (`--measures-file`) < measurements
given in the request** (`--measures`, `measures_cm`, `measures_in`). The measurement table
in the instructions marks profile values with the source `profile`. Children's profiles
older than **6 months** produce a warning (please measure again). `profiles.py show <name>`
prints the growth since the previous entry and the next kids' size; `profiles.py export
<name> file.smis` writes the profile as an XML measurement file.
